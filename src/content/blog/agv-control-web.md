배터리 이송 AGV의 제어 프로그램과 별도로, 브라우저에서 로봇 상태를 보고 명령을 보낼 웹 페이지를 만들었습니다. 이 작업은 제가 2024년 5월에 저장소와 Vue 프로젝트를 만들며 시작했습니다. 이 글은 이후 다른 로봇용으로 확장한 별도 브랜치가 아니라, 1세대 AGV용 기본 브랜치의 구현을 다룹니다.

## 왜 웹 화면을 만들었나

로봇 제어 프로그램은 장치와 통신하지만, 사람이 확인하는 정보는 현재 위치, 목표 위치, 적재 여부, 정지 상태와 명령 응답입니다. 상태를 보는 화면과 명령을 입력하는 화면을 붙여 두는 방향으로 구성했습니다. 제어 프로그램을 웹으로 옮긴 것이 아니라, 로봇과 통신하는 조작 창을 만든 작업입니다.

전체 화면에는 AGV 1~3호기를 나란히 배치했고, 호기별로 따로 보는 탭도 만들었습니다. 같은 로봇 패널을 재사용하고 호기 식별값으로 접속 대상과 메시지를 구분합니다. 패널에는 현재 위치와 목표 위치, 비상정지, 주행·리프트 인터록, 배터리 적재 여부와 리프트 높이를 표시합니다.

## 내가 맡은 부분

프로젝트 초기 구성부터 화면 컴포넌트, 상태 저장소와 WebSocket 통신 코드를 작성했습니다. Vue 3와 Vuetify로 화면을 구성하고, Pinia에 호기별 위치와 차종 등 공유 상태를 보관했습니다. 로봇별 패널에서 수신한 상태를 화면과 저장소에 반영하는 방식입니다.

조작부에는 목표 위치와 차종 선택, 리프트 동작 선택, 서보 켜기·끄기, 상판 원점 초기화와 적재 정보 초기화 등을 연결했습니다. 선택한 값을 로봇 명령의 파라미터로 바꾸어 전송합니다. 화면에는 현재 적용 중인 차종과 적용 예정 차종을 따로 표시합니다. 로봇 명령에서 수신한 값과 사용자가 선택한 값을 구분해 보는 항목입니다. 이 표시가 실제 장치 설정까지 읽어 검증하는 기능은 아닙니다. 여기서 제가 만든 것은 명령을 구성하고 보내는 웹 쪽 처리이며, 하위 장치를 실제로 움직이는 제어 로직과는 구분합니다.

## 구조와 동작

브라우저는 각 로봇의 rosbridge에 WebSocket으로 접속합니다. 별도의 웹 전용 장치 드라이버를 두지 않고, JSON 메시지로 ROS 토픽을 구독하거나 명령을 발행합니다. 접속이 열리면 모니터링과 명령 응답 등을 구독하고, 수신한 토픽에 따라 상태를 갱신합니다. 연결이 닫히면 다시 접속을 시도하는 처리도 넣었습니다.

명령 전송과 응답 표시는 다른 경로입니다. 사용자가 조작하면 명령과 파라미터를 발행하고, 로봇이 보낸 응답은 최근 기록으로 화면에 쌓습니다. 따라서 버튼을 눌렀다는 사실을 작업 완료로 표시하는 구조는 아닙니다. 다만 실제 로봇과 연결한 최신 상태에서 모든 명령·응답 조합을 다시 시험하지는 않았습니다.

핀 정렬 확인용 대화상자에는 좌우 카메라 이미지를 표시하고, 재시도와 후속 상승 명령을 보내는 버튼을 구성했습니다. 필요할 때 이미지 토픽을 구독하고 이미지를 받으면 구독을 해제하는 방식입니다. 연속 영상 감시 화면이라기보다 작업 확인에 필요한 이미지를 받는 구현입니다. 대화상자를 여는 상태 신호가 현재 로봇 제어 코드에서도 같은 의미인지는 별도로 확인해야 합니다.

## 구현했지만 지금은 꺼진 부분

초기에는 웹의 상태 저장소에 위치 점유와 합류 구간을 보고 일시정지를 판단하는 처리도 작성했습니다. 하지만 2024년 8월, 일시정지 알고리즘을 서버로 통합한다는 변경에서 웹 쪽 판단 호출을 주석 처리했습니다. 기본 브랜치에도 해당 함수는 남아 있지만 모니터링 수신 시 호출하지 않습니다. 따라서 이 페이지가 지금도 로봇 간 통행을 판단하는 관제라고 설명하지 않습니다.

작업 초기화 버튼도 최신 제어 프로그램에 추가한 작업 전용 취소 명령과 다릅니다. 이 페이지에는 비상정지와 해제 명령을 조합하는 이전 방식이 남아 있습니다. 제어 프로그램이 바뀌었다고 이 웹 화면까지 함께 갱신된 것은 아니므로, 현재의 제어 인터페이스와 맞는지 확인이 필요합니다.

## 지금 상태

이 글의 대상인 1세대 AGV 웹 페이지는 기본 브랜치의 마지막 커밋이 2026년 2월 4일이며, 그 이후 해당 브랜치의 개발은 멈춰 있습니다. 저장소의 다른 브랜치에는 후속 AMR 작업이 있지만, 이를 1세대 화면의 유지보수나 현장 사용 근거로 보지는 않습니다.

분리한 소스 사본에서 의존성을 설치하고 배포용 빌드가 완료되는 것은 확인했습니다. 번들 크기 경고는 남아 있으며, 빌드 성공이 실차 연동 성공을 뜻하지는 않습니다. 이 페이지의 현재 배포와 일상적인 현장 사용은 확인하지 못했습니다. 최신 로봇과의 명령 호환성, 카메라 확인 신호와 재연결 동작도 실차 검증을 마친 상태로 쓰지 않습니다.
