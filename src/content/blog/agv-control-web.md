배터리 이송 AGV의 상태를 브라우저에서 확인하고 명령을 보낼 수 있도록 웹 인터페이스를 만들었습니다. 로봇 제어 프로그램 자체를 웹으로 옮기는 대신, 작업자가 필요한 정보와 조작을 한 화면에서 다루도록 구성했습니다.

## 로봇 데이터를 화면으로 연결하기

Vue와 Vuetify로 화면을 만들고, Pinia에서 로봇별 공유 상태를 관리했습니다. 브라우저와 로봇 사이는 rosbridge의 WebSocket 통신으로 연결했습니다. 여러 로봇을 같은 컴포넌트로 표시하되, 호기별 상태와 접속을 구분하는 방식입니다.

프로젝트 초기 구성부터 화면 컴포넌트, 상태 관리와 통신 코드를 작성했습니다. 위치와 적재 상태를 표시하고 목표 위치, 작업 종류 등 사용자가 선택한 값을 로봇 명령으로 바꾸는 처리를 맡았습니다. 작업 확인용 카메라 이미지도 화면에 연결했습니다.

## 명령 전송과 완료 표시를 나누기

화면에서 버튼을 누른 것과 로봇이 실제 작업을 끝낸 것은 다릅니다. 명령을 보내는 경로와 로봇의 응답을 받아 표시하는 경로를 나눠, 요청과 결과를 구분하도록 했습니다. 로봇 통신의 비동기적인 흐름을 작업자 화면으로 옮기는 경험이었습니다.

## 지금 상태

1세대 기본 브랜치에는 후속 변경이 없는 상태입니다. 배포용 빌드는 확인했지만 현재 현장 사용 여부는 확인하지 못했습니다. 이 글은 저장소 시작 이후 구현을 돌아본 기록입니다.
