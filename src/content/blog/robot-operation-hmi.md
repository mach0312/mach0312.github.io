현장의 로봇은 자동 운전만큼 사람이 상태를 보고 직접 다루는 일이 많습니다. 작업자와 개발자가 로봇을 확인하고 조작하는 도구를 1세대 AGV부터 2세대 AMR까지 개발했습니다.

## 1세대: 게임패드 조작과 웹 화면

1세대 AGV 제어 프로그램에서 게임패드 입력을 직접 읽고 버튼과 축을 로봇 동작에 연결하는 수동 조작을 만들었습니다.

여러 AGV의 상태를 한 화면에서 보고 명령을 보내는 웹 페이지도 Vue와 rosbridge로 개발했습니다. 호기별 화면에서 위치와 장치 상태를 확인하고, 보낸 명령과 로봇의 응답을 따로 표시하며, 좌우 카메라 이미지를 확인하는 화면도 넣었습니다.

## 2세대: 3D 상태 화면과 조작 연습

2세대 AMR용 화면은 Vue 3와 three.js로 새로 만들었습니다.

- 로봇 모델(URDF)에 실제 관절 값을 반영해 3D로 표시하고, 비상정지가 범퍼에서 왔으면 해당 면을 강조합니다.
- 명령마다 보냄, 수락, 완료 시각을 기록하고, 명령이 거부되면 이유와 해결 방법을 안내합니다.
- 로봇에 접속하지 않고 로봇 코드의 조작 규칙대로 반응하는 조작 연습 화면을 만들어 Windows 데스크톱 앱(Tauri)으로 배포하고, 자동 업데이트를 붙였습니다.

전방향 로봇을 조이스틱으로 다루기 쉽도록, 차체가 돌아가 있어도 조작을 시작한 방향을 기준으로 움직이고 오른쪽 스틱으로 목표 방향을 정하는 조작 노드와 가속도 제한 노드도 만들었습니다.

## 지금 상태

2세대 화면은 지금도 기능을 더하고 있습니다. 1세대 웹 페이지는 2026년 2월 이후 기본 브랜치에 변경이 없고, 현재 현장에서 쓰이는지는 확인하지 못했습니다. 조작 연습을 마쳤다고 실기 운전 자격이 생기지는 않습니다. 글 날짜는 1세대 조작 기능을 처음 만든 날이며, 내용은 이후 작업까지 포함한 회고입니다.
