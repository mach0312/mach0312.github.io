피트인에서 2세대 배터리 이송 AMR의 소프트웨어를 개발하고 있습니다. 이중 조향 구동으로 전방향 이동을 하고, 리프트와 상판 장치를 이용해 배터리를 옮기는 로봇입니다.

1세대 제어 코드를 바탕으로 시작해, 주행과 작업 장치, 관제 통신의 역할을 나누는 방향으로 구조를 정리했습니다. 이 글은 회사 비공개 구현의 세부 대신 시스템 구성과 제가 맡은 부분을 소개합니다.

## 주행부터 관제까지 연결하기

시스템 제어는 명령과 장치 상태를 다루고, 내비게이션은 위치 추정과 경로 주행을 담당합니다. 관제 연결부는 주문을 로봇 명령으로 바꾸고 진행 상태를 보고합니다. 각 기능을 ROS 2 인터페이스로 연결하되, 통신 성공과 실제 작업 완료를 구분하도록 구성했습니다.

제가 맡은 주요 작업은 다음과 같습니다.

- 시스템 상태 관리, 명령 처리와 장치별 인터록 구성
- 이중 조향 기구학을 적용한 ros2_control 제어기 개발
- Nav2 기반 주행 구성과 경로 추종, PGV 정렬 제어
- VDA5050 관제 연결과 로봇 상태 표시·조작 도구 개발

센서와 구동 장치의 통합은 동료와 함께 진행했습니다. Nav2, ros2_control 등 공개 패키지를 활용하면서 로봇 특성에 필요한 제어와 인터페이스를 추가한 작업입니다.

## 기능 경계에서 생기는 문제 다루기

개별 노드가 동작하더라도 전체 작업이 이어지는지는 별개의 문제입니다. 명령 실패나 통신 단절, 작업 취소가 다른 계통에 어떤 상태로 전달되는지를 중요하게 봤습니다. 주행과 장치 제어, 관제 상태를 함께 다루는 경험을 쌓고 있습니다.

## 지금 상태

개발과 현장 검증을 진행 중이며 무인 운용 승인은 보류 상태입니다. 주행·장치·관제의 통합 검증이 남아 있습니다. 글 날짜는 초기 저장소 생성일이며 이후 개발 내용을 함께 정리했습니다.
