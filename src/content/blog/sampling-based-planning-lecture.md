[Sampling-Based-Planning_Tutorial](https://github.com/mach0312/Sampling-Based-Planning_Tutorial)은 샘플링 기반 경로 계획을 설명하기 위해 Python 예제, 강의 노트, 영상을 묶은 저장소입니다. 경희대학교 RCI Lab 소속으로 정리한 자료입니다. 글 날짜는 저장소 생성일인 2025년 11월 20일을 기준으로 두었으며, 본문은 2026년 11월 11일에 자료와 실행 상태를 다시 확인한 회고입니다.

강의는 알고리즘 이름을 소개하는 데서 끝내지 않고, 샘플을 뽑아 경로를 반환하기까지 코드가 어떤 순서로 실행되는지 함께 살펴보는 구성입니다. 여기서 만든 것은 교육용 설명과 예제 묶음입니다. 실제 AMR의 전역 계획기나 새로운 경로 계획 알고리즘을 개발한 연구로 소개하지 않습니다.

## 이론 설명 다음에 코드를 읽기

[YouTube 재생목록](https://www.youtube.com/playlist?list=PL5zS4AjTJMs8wwZQyWds0j8TPxq3N_OpD)에는 영상 11개가 있습니다. 확인한 메타데이터에서는 모두 2025년 11월 20일 업로드이며, 링크로 볼 수 있는 일부공개 상태입니다. 강의의 큰 순서는 다음과 같습니다.

1. 경로 계획 개요와 격자 기반 방법, 샘플링 기반 방법의 비교
2. PRM과 RRT 설명, 각 알고리즘 코드 리뷰
3. RRT*와 RRT-Connect 설명, 각 알고리즘 코드 리뷰
4. Informed RRT* 설명과 코드 리뷰
5. 추가 알고리즘 소개
6. 실제 적용 시 유의사항

재생목록에서는 RRT-Connect 코드 리뷰가 RRT* 코드 리뷰보다 먼저 놓여 있습니다. 강의 번호대로 따라가려면 `Lecture_03-02`의 RRT*를 보고 `Lecture_03-03`으로 넘어가면 됩니다. 저장소의 PDF 강의 노트도 같은 주제별로 묶었습니다.

## 예제에서 비교하는 것

PRM 예제는 샘플을 연결해 로드맵을 만들고 그 그래프에서 경로를 찾습니다. RRT는 최근접 노드를 고르고 샘플 방향으로 트리를 확장하는 과정을 보여 줍니다. RRT*에서는 비용을 기준으로 부모를 선택하고 주변 노드를 재연결하는 부분을 읽습니다.

Informed RRT*에서는 경로를 찾기 전후의 샘플링 영역이 어떻게 달라지는지 봅니다. 이미 찾은 경로의 비용을 이용해 타원 내부로 샘플링을 좁히는 코드와 그림을 함께 설명합니다. Connect 예제는 시작점과 목표점 쪽 트리를 번갈아 확장해 연결하는 과정을 다룹니다. 이 예제가 원 논문의 모든 절차를 그대로 구현한다고 단정하지는 않습니다.

RRT* 코드에는 재연결된 노드를 표시하는 시각화와 shortcut 방식의 경로 스무딩도 있습니다. 경로를 찾았다는 사실 외에, 트리와 경로가 어느 부분에서 바뀌는지 확인하는 데 쓰는 장치입니다. 각 예제의 실행 방법과 주요 파라미터는 `Examples/README.md`에 적었습니다.

## 예제의 출처와 설명의 범위

이 코드를 모두 처음부터 독자적으로 작성한 구현이라고 설명하지 않습니다. PRM, RRT, Informed RRT* 등의 계산과 탐색 흐름은 Atsushi Sakai와 기여자들의 [PythonRobotics](https://github.com/AtsushiSakai/PythonRobotics) 예제와 공통되는 부분이 확인됩니다. 한글 설명과 강의 구성을 제가 정리한 일과, 밑바탕 예제 구현의 출처는 구분해야 합니다.

저장소에는 알고리즘 논문 참고문헌이 있지만, 확인한 README와 Python 파일에서 PythonRobotics에 대한 출처 표기는 찾지 못했습니다. 원 구현의 출처와 라이선스를 별도로 정리하는 문서 보완이 남아 있습니다. 공통 코드가 있다는 사실만으로 각 줄의 작성 경위를 모두 확인했다고 말하지도 않습니다.

예제는 Python과 NumPy, Matplotlib을 사용하며 PRM에는 SciPy도 필요합니다. 이번 확인에서는 화면 표시를 끈 환경에서 예제 파일을 각각 실행해 정상 종료를 확인했습니다. 이 검사는 실행 경로를 확인한 것이지, 여러 난수 조건에서의 성공률이나 알고리즘 간 속도 비교 실험은 아닙니다.

## 경로를 찾는 것과 주행하는 것은 다릅니다

마지막 강의에서는 충돌 검사와 여유 거리, 확장 길이, 목표 편향, 계산 시간 제한을 다룹니다. 기하학적 경로를 실제 제어기가 따라갈 수 있는 궤적으로 만드는 문제는 별도라는 점도 짚습니다. 속도와 가속도, 곡률 및 비홀로노믹 제약을 고려해야 하기 때문입니다.

추가 알고리즘 강의에는 BIT*, Quick-RRT*, Zonal RL-RRT, NIRRT*가 나오지만, 이들까지 저장소에 구현한 것은 아닙니다. 영상에서 소개한 범위와 실행 가능한 예제의 범위를 구분합니다.

## 지금 상태

강의 영상 11개와 강의 노트, Python 예제를 올리는 작업은 마쳤습니다. 중단된 로봇 개발 프로젝트가 아니라 완료한 강의 자료로 남겨 둔 저장소입니다.

다만 예제 출처와 라이선스 문서 보완, 의존성 버전 고정, 자동 회귀시험은 끝나지 않았습니다. 실제 AMR 통합이나 실기 주행 성능 검증도 이 강의의 완료 범위에 포함하지 않습니다. 자료를 보는 사람이 코드의 흐름을 따라가고 조건을 바꿔 실행해 볼 수 있는 교육용 묶음까지가 현재 상태입니다.
